# 简易通讯录管理系统 (Contact System)

一个基于 C 语言实现的命令行通讯录系统，支持数据的断电持久化。本项目采用多文件工程化结构与 Makefile 进行构建管理。

## ✨ 核心功能
- **增删改查**：基于单链表实现的联系人（姓名、年龄、电话）管理。
- **数据持久化**：使用 C 语言二进制文件 I/O (`fread`/`fwrite`) 将链表数据保存到本地硬盘，解决断电丢失问题。
- **动态内存管理**：严格配对 `malloc` 和 `free`，防止内存泄漏和野指针。

## 🛠️ 技术栈与工程化
- **语言**：C (C99)
- **构建工具**：Makefile
- **调试工具**：GDB (通过 GDB 单步调试排查过链表断链与 Use-After-Free 漏洞)

# 运行
